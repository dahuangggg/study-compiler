## Learning Objectives

Explain how attention lets one token use information from other tokens.

## Intuition

Each token asks which other tokens are relevant to its current job, then combines information from the useful ones.

## Example

In “the animal was tired because it ran”, the token “it” can use information from “animal” to resolve what the pronoun refers to.
